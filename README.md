# tinygit
Rust library and CLI implementing a subset of Git.

## Functionality
- Lazy API over loose objects
- Packfiles and packfile indexes
- Refs and branches
- Index/working tree

## CLI Usage
```
One of the following subcommands must be present:
    help
    hash-object
    ls-buckets
    ls-objects
    parse-object
    parse-pack
    unpack-objects
    log
    index-pack
    add
    commit
```
